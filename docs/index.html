Two-Phase Commit
+ registro imutável na Sepolia

Uma transferência bancária distribuída coordenada pelo protocolo 2PC, com a decisão final (COMMIT ou ABORT) gravada num smart contract Ethereum como trilha de auditoria.

Ver animação Código no GitHub Contrato na Etherscan

1. O fluxo, passo a passo

Cliente pede a transferência. O coordenador pergunta aos bancos se podem efetivar. Se todos respondem YES, ele decide COMMIT; se algum responde NO, decide ABORT. A decisão final é registrada na blockchain.

Log do coordenador

    2. O que ficou gravado on-chain

    Os botões abaixo consultam o contrato real na Sepolia via RPC público e mostram os 5 campos do records(transactionId): id, decisão, timestamp, coordenador e valor.

    Clique em um dos botões para buscar o registro.
